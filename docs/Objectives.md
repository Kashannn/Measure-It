## 2. Formal Measurable Objectives

### MO-1: Real-World Measurement Accuracy (Mandatory)

| ID | Field | Entry |
|---|---|---|
| **MO-1** | **What is measured** | Mean Absolute Error (MAE) and Mean Percentage Error (MPE) between system optical measurement and digital caliper ground truth (width & height in mm) across held-out test instances. |
| | **How** | A test script (`measurement/benchmark_accuracy.py`) loads 10+ held-out test photos, executes the single-command measurement pipeline, and compares output dimensions against manually verified ground truth caliper measurements ($0.02\text{ mm}$ vernier resolution). |
| | **Target** | **MAE $\le 1.50\text{ mm}$** and **MPE $\le 2.0\%$** across all test instances. Worst-case single-axis error $\le 3.00\text{ mm}$. |
| | **Conditions** | Test images taken with calibrated camera, undistorted, ArUco reference marker and target object placed coplanar on a flat table under normal indoor lighting (300–600 lux), camera tilt within $15^\circ$ of perpendicular (face-on). |
| | **Not included** | Photos where the reference marker is occluded by more than 10%, severe direct glare covering object edges, or camera tilted beyond $30^\circ$ (which triggers the defensive rejection guardrail). |

---

### MO-2: Segmentation Quality on Unseen Test Split

| ID | Field | Entry |
|---|---|---|
| **MO-2** | **What is measured** | Mean Intersection over Union (mIoU) and Mean Average Precision (mAP@0.5) of the custom DeepLabV3+ segmentation model on the strictly held-out test set. |
| | **How** | An automated evaluation script (`models/evaluate.py`) evaluates model checkpoint predictions against human-annotated binary ground truth masks on the isolated 10% test split. |
| | **Target** | **Mask IoU $\ge 0.88$** and **mAP@0.5 $\ge 0.92$** on the test split. |
| | **Conditions** | Test set images processed through camera undistortion, evaluated at $512 \times 512$ model input resolution, sigmoid decision threshold $\tau = 0.50$. |
| | **Not included** | Test images deliberately corrupted with extreme non-coplanar tilt or severe edge cut-offs designed for breaking boundary tests. |

---

### MO-3: Impact of Lens Undistortion on Measurement Accuracy (Item 6 Proof)

| ID | Field | Entry |
|---|---|---|
| **MO-3** | **What is measured** | Error Delta ($\Delta_{\text{MAE}}$ and $\Delta_{\text{MPE}}$) when measuring the exact same physical test set images with vs without OpenCV camera calibration undistortion. |
| | **How** | Script `measurement/ablation_undistort.py` executes the metrology pipeline twice per image: once on the raw distorted photograph and once on the undistorted image, producing a side-by-side error delta table. |
| | **Target** | Undistortion improves measurement accuracy by at least **$1.0\text{ mm}$ MAE reduction** for objects placed in the outer 30% radial border of the frame. |
| | **Conditions** | Identical segmentation model weights, identical ArUco detection pipeline, varying object placement from frame center to frame periphery. |
| | **Not included** | Synthetic or artificial distortion transformations; all tests use natural lens barrel distortion from candidate camera. |

## 3. Reporting Protocols & Rules

1. **No Untested Claims**: Every number in the final report must be generated by a runnable script with raw stdout logs committed or saved.
2. **5-Trial Timing Rule**: For any latency benchmarks, the system executes 5 warmup runs followed by 5 recorded runs, reporting `median [min, max]`.
3. **Statistical Completeness**: Single-number summaries are forbidden. Error reports must include:
   - Full per-instance comparison table (10+ rows).
   - Mean Absolute Error (MAE).
   - Mean Percentage Error (MPE).
   - Median Error.
   - Maximum (Worst-case) Error.
